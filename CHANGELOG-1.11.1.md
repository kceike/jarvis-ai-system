# JARVIS 1.11.1 — Help Center Update

## New functions

- Responsive **HELP** button in the main header.
- Searchable catalog covering every supported JARVIS command and major system function.
- Step-by-step tutorials for conversations, missions, Screen Vision, Windows IT Copilot, memory, synchronization, installation, updating, and saving the guide.
- **Load Example** buttons place safe example commands in the composer without executing them automatically.
- **Copy Guide** copies the complete command, function, and tutorial guide.
- **Save Guide (.md)** stores an offline local copy and downloads `JARVIS-Help-Guide-1.11.1.md`.
- `/help`, `/tutorial`, “show commands,” and “what can you do” open the Help Center.

All JARVIS 1.11.0 and earlier functions remain available.

- Worker and desktop JavaScript syntax checks pass.
- Automated tests cover the Help Center button, search, command catalog, tutorials, saved Markdown guide, preserved keyboard behavior, desktop installer, updater, Mission Control safety, Windows controls, and Cloudflare APIs.

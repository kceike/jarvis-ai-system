# JARVIS 1.11.2 — Help Center Scrolling Fix

- The Help Center title, close button, search field, Copy Guide, and Save Guide controls now remain in a fixed opaque header.
- Only the command, function, and tutorial guide scrolls.
- Scrolling content can no longer appear behind or overlap the title area.
- Opening Help resets the guide to the top for a predictable starting position.
- The layout remains responsive on desktop, tablet, and mobile screens.
- The saved offline guide now identifies version 1.11.2.
- Every feature and safety control from JARVIS 1.11.1 remains available.
